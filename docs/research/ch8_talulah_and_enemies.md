# 第八章“怒号光明”：塔露拉 Boss 战与敌人资料

调研日期：2026-10-07。数据源以 PRTS 为准，取法是 MediaWiki API 的 wikitext，加上 `<敌人页>/spine` 子页面，也就是页面里 `SPINEDATA` 的数据源，已对照“不死的黑蛇”页面 HTML 确认一致。萌娘百科移动版这次返回 Cloudflare 质询页（HTTP 403 “Just a moment...”），没有绕过，所以萌百资料一条都没用上。

## 结论摘要

- **关卡编号**：第八章没有“8-1 ~ 8-20”这种编号。实际是三条线：R8-1 ~ R8-11（过去线）、M8-1 ~ M8-8（现在线，其中 M8-1 ~ M8-5 是 `st_08-0x` 纯剧情关）、JT8-1 ~ JT8-3（汇合），另有 TR-8 教学关，以及绝境关 H8-1 ~ H8-4（狂夜行动）。社区说的“8-16/8-17”是内部关卡 ID：`main_08-16` 是 **JT8-2 睁眼，便是日暮**，`main_08-17` 是 **JT8-3 昂首，足践烈焰**。
- **塔露拉战分两关，Boss 是两个不同的敌人**：
  - JT8-2（`main_08-16`）的 Boss 是 **塔露拉**（`enemy_1503_talula`，PRTS id 1132）。单阶段，**生命低于 50% 时狂暴**：防御力 +100%，法术抗性 +80%，技能改用冷却更短的版本（日冕 40s→15s，烈焚灼息 19s→7s）。不被阻挡时远程攻击，造成 40% 法术伤害；被阻挡时近战攻击，造成 100% 真实伤害。突袭条件：塔露拉开场即狂暴。
  - JT8-3（`main_08-17`）的 Boss 是 **“不死的黑蛇”**（科西切附身的塔露拉，`enemy_1515_bsnake`，id 1145）。流程是两条命加两次【不息恶火】：
    1. 黑蛇形态（50000 HP）。普攻造成真实伤害并附加【烈焚灼息】；“点燃”每 19s 给 2 人上灼烧；“引爆”每 35s 一次；带灼烧的单位对黑蛇只造成 50% 伤害。
    2. 第一次被击败后用 5s 重生、回满血，进入狂暴：生命上限 +50%，攻击力 +50%。随后无敌并释放【不息恶火】：每 2s 从左侧放一列火球，共 10 次。28s 后变回黑蛇形态，并有 15s 无敌，之后周期召唤“能量聚合体”。
    3. 第二次被击败后，5s 后再放一次【不息恶火】，28s 后退场。
  - **能量聚合体**（`trap_021_flame`）是黑蛇狂暴后召唤的敌方装置：6000 HP，25s 后自爆，向四个方向发射火球，每发 1000 法术伤害并附加【烈焚灼息】。H8-4 中为 1500，JT8-3 突袭再加 400。
- **核心机制【烈焚灼息】**：真实伤害 DoT，初始 50/s，30s 内线性升到 230/s，持续 30.5s；不可叠加，重复施加只刷新持续时间，可被抵抗，结束后伤害重置。斗士塔露拉版本更高：200/s，20s 内升到 400/s。
- **Spine**：本章 32 个敌人 `.skel` 的文件头全部是 **Spine 3.8.99**，是用 Range 请求读文件头核实的。导入 STS2 要先转成 4.2（见 sts2-spine-enemy-import skill）。三个 Boss 的动画名已用 Spine 3.8.99 `-i` 读出：
  - 塔露拉：`Attack_1, Attack_2, Default, Die, Idle, Move, Skill_1, Skill_2`
  - 黑蛇：`Attack_A/B, Default, Die, Idle_A/B, Move_A/B, Reborn_1_Start/Idle/End, Reborn_2_Start/Idle/End, Skill_1_A/B, Skill_2_A/B, Skill_3`（19 个）
  - 能量聚合体的 Spine 在 PRTS 登记了路径，但文件 404，**未核实**。
- **BGM**（PRTS 游戏内音乐一览，曲目均在塞壬唱片《明日方舟OST3》，专辑 cid 9399）：
  - JT8-2 全程，以及 JT8-3 黑蛇重生前：**《交锋》**，`m_bat_talulha_combine`，塞壬 cid 125005。
  - JT8-3 黑蛇重生后：**《塔露拉·雅特利亚斯》**，`m_bat_talulhahard_combine`，塞壬 cid 048731。
  - H8-2、H8-4 用法相同。
